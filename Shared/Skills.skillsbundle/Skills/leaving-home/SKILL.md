# Leaving home

Help the person leave with the car locked and the home being cleaned.

1. Check the car with the device status tool. If the car is unlocked, lock it with the lock car tool.
2. If the person named a scene for leaving, or a scene clearly meant for leaving exists (for example "Leaving Home" or "Away"), run it with the activate scene tool. If no scene clearly matches, skip this step rather than guessing.
3. Check Cleanbot with the device status tool. If it's idle or charging, start a whole-home clean with the start robot tool. If it's already cleaning, leave it alone.
4. If the person is driving somewhere, offer to start the car's climate control. Don't start it without asking.
5. Finish with one short summary: whether the car is locked, its battery and range, which scene ran, and whether Cleanbot started.

Never unlock the car as part of this skill.

# Checking the appliances

1. Pick the devices to check:
   - Laundry: the washer and the dryer.
   - Dishes: the dishwasher.
   - "What's running" or "is anything still going": the dishwasher, washer, dryer, and Cleanbot.
2. Call the device status tool once for each device.
3. Combine the results into one short answer. Lead with anything that's finished so the person can unload it, then anything still running with its expected finish time. Leave out idle devices unless the person asked about them by name.
4. FluxHaus can only report the status of the washer, dryer, and dishwasher. It can't start or stop them, so explain that if asked.
